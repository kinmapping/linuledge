## ベストプラクティスから学ぶコスト最適化の基本

AWS Well-Architected Framework の考え方

クラウド環境における信頼性やセキュリティの担保、コスト最適化を実現するためのフレームワーク

- 優れた運用効率
- セキュリティ
- 信頼性
- パフォーマンス効率
- コスト最適化
- サステナビリティ(持続可能性)

### コスト最適化を行うための柱

- **コスト意識の文化を醸造**:

  チーム全体でコストに対する意識と責任の共有をする。
  開発するシステムやアプリケーションが最適なサービスを使っているのか、無駄なコストを費やしていないかなどをメンバー同士でチェックしなければならない。

- **リザーブドインスタンスを活用**: 長期利用の場合はリソースを事前に購入

  EC2 では長期の利用(1 年または 3 年)を前提に購入することで、割引が大きくなる。
  1 年の場合は、4 割弱、3 年の場合は、6 割弱がオンデマンドと比較して割引される。
  さらに、料金を一括して支払う全額、前払いを選択すればさらに安価に利用できる。

- **適切なインスタンスタイプを選択**: アプリケーションの要件に応じて選択
- **自動スケーリングを実装**: 負荷の変動にリソースを増減させて対応
- **ストレージの最適化**: アクセス頻度や用途を考慮して選択

- **効果的なデータ転送**: 外部とやり取りする際にデータ転送量を抑制
- **サーバーレスアーキテクチャを採用**: 管理コストを低減し、リソースを効果的に利用
