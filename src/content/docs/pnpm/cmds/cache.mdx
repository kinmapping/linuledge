## サブコマンド

### cache list

利用可能なパッケージのメタデータ・キャッシュを一覧表示します。 glob によるフィルタリングをサポートしています。

### cache list-registries

ローカルにメタデータキャッシュを持つすべてのレジストリをリストする。

### cache view

指定されたパッケージのキャッシュから情報を表示します。

### cache delete

指定されたパッケージのメタデータキャッシュを削除します。 パターンをサポートしています。
