パッケージストアの管理

## サブコマンド

### start

ストアとのすべてのやりとりを行うサーバを起動する。 他のコマンドは、ストアに関連するタスクをこのサーバーに委譲する。

### stop

store サーバーを停止する。

### status

実行中のサーバーに関する情報を表示する。
