## サブコマンド

### status

ストア内のパッケージが変更されていないかチェックします。
パッケージの内容が開梱時と同じであれば、終了コード 0 を返します。

### add

機能的には `pnpm add` と同じですが、ストア外のプロジェクトやファイルを変更することなく、新しいパッケージをストアに直接追加します。

### prune

ストアから参照されていないパッケージを削除する。

参照されないパッケージとは、システム上のどのプロジェクトでも使われていない パッケージのことです。 例えば、依存関係が冗長化された場合などです。

例えば、pnpm のインストール中に、`foo@1.0.0` パッケージが `foo@1.0.1` に更新されたとします。pnpm は自動的にパッケージを削除しないので、`foo@1.0.0` をストアに保持します。 パッケージ `foo@1.0.0` がシステム上の他のプロジェクトで使われていない場合、参照されなくなります。 `pnpm store prune` を実行すると、`foo@1.0.0` がストアから削除されます。

`pnpm store prune` を実行しても有害ではなく、プロジェクトに副作用はありません。 将来インストールする際に削除したパッケージが必要になった場合、pnpm はそれらを再度ダウンロードします。

`pnpm store prune` を実行しても有害ではなく、プロジェクトに副作用はありません。
将来インストールする際に削除したパッケージが必要になった場合、pnpm はそれらを再度ダウンロードします。

`pnpm store prune` を時々実行してストアを整理するのがベストプラクティスですが、あまり頻繁には行わないでください。 時々、参照されていないパッケージが再び必要になることがあります。 これは、ブランチを切り替えて古い依存パッケージをインストールするときに発生する可能性があります。この場合、pnpm は削除されたパッケージをすべて再ダウンロードする必要があり、インストール処理が一時的に遅くなります。

ストアサーバー (store server) が稼動している場合、このコマンドは禁止されていますのでご注意ください。

### path

アクティブストア・ディレクトリへのパスを返します。
