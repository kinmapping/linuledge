## go mod について

`go mod` はモジュールを管理するためのコマンドです。

モジュールのサポートは 'go mod' だけでなく、すべての go コマンドに組み込まれています。
例えば、依存関係の日々の追加、削除、アップグレード、ダウングレードは 'go get' を使用して行う必要があります。
モジュール機能の概要については 'go help modules' を参照してください。

ある程度の規模のプロジェクトになると Go のモジュール機能を使用したほうが便利になります。
まずプロジェクトのディレクトリを作成して `go mod init` コマンドを実行します。

**[モジュールとパッケージについて](/golang/base/module-and-package)**

```bash frame=none
# プロジェクトのディレクトリを作成してカレントディレクトリを移動
mkdir hello_world
cd hello_world

# モジュールを初期化、ディレクトリ内に go.mod ファイルが作成される
go mod init hello_world
# go: creating new go.mod: module hello_world
```

モジュールファイルの内容は以下

```go title="hello_world/go.mod"
module hello_world

go 1.21.1
```

.go ファイルを作成してモジュールとしてビルドします。

```bash frame=none
touch main.go
# main.go ファイルを編集する

go mod tidy
go build
```

go.mod ファイルがあると、ビルド対象のファイルを指定しなくてもそのディレクトリ内の.go ファイルを解析して、コンパイルしてビルドします。`module hello_world` と書かれているので、`hello_world` というコマンドが作成されます。

`go tidy` コマンドは、`go.mod` ファイルに記載されているモジュールの依存関係を更新します。ソースファイルを解析して、必要なサードパーティのライブラリのダウンロードや不要になったファイルの削除などを行います。

### syntax

```bash frame=none
go mod <command> [arguments]
```
