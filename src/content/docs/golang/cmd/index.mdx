## go コマンドについて

開発環境のインストールによって、一連の開発用ツールが利用可能になります。すべてのツールは `go` コマンドで実行できます。コンパイラ、コードのフォーマット、リンター、依存性管理、テストランナー、ビルド、パッケージのインストールなどがあります。
