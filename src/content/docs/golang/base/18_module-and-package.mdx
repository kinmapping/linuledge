## モジュールとパッケージについて

モジュールとパッケージは Go 言語の基本的な概念です。
モジュールはパッケージの集まりで、パッケージはソースコードのファイルの集まりです。

モジュールを公開する場合は 「github.com/user/repo」 のような URL を使用します。  
リポジトリの場所と機能を表す名称を指定します。
