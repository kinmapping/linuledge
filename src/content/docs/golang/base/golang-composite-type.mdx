## 配列

Go 言語にも配列がありますが、ほかの言語と使い、直接使うことはありません。

ゼロ値: `nil`

配列の各要素は指定された型でなければなりません。

```go
var 配列名 [要素数]型
// ex.
// 要素数 3 の int 型の配列
var x [3]int
```

この宣言で 3 つの要素数をもつ配列 `x` が宣言されます。
配列内のすべての要素は `int` 型のため、ゼロ値 `0` を持った要素が 3 つ格納されています。

```go
// 要素数 3 の int 型の配列を宣言し、その要素に 1, 2, 3 を代入
var x [3]int{1, 2, 3}

var x = [12]int{1, 5: 4, 6, 10: 100, 15}
// 要素数 12 の int 型の配列 [1, 0, 0, 0, 0, 4, 6, 0, 0, 0, 100 15]
```

### `...` を利用した初期化

```go
var x = [...]int{1, 2, 3}
// 要素数 3 の int 型の配列 [1, 2, 3]

// 配列の同士の比較
var y = [3]int{1, 2, 3}

x == y // true
x != y // false
```

### 配列の要素に値を代入

```go
var x = [3]int{1, 2, 3}
x[0] = 10
x[1] = 20
x[2] = 30
```

最後の要素を超えるインデックスを指定したり、インデックスとして負の値を指定したりはできません。

```go
var x = [3]int{1, 2, 3}
x[3] = 4 // エラー
x[-1] = 4 // エラー
```

インデックスを変数で指定することもできます。

```go
var x = [3]int{1, 2, 3}
var i = 2
x[i] = 4

i := 3
// 範囲外のインデックスを指定した場合はエラーになります。
x[i] = 4 // エラー
```

### len() 関数 (配列の長さを取得)

組み込み関数 len で配列の長さ(要素数)を取得できます。(インデックスの最大値 + 1)

`len(配列)`

```go
var x = [3]int{1, 2, 3}
len(x) // 3

var y = [10]int{1, 2, 3}
len(y) // 10

var z = [10]int{}
len(z) // 10
```

### Go 言語の多次元配列

```go
var x = [2][3]int{{1, 2, 3}, {4, 5, 6}}
// 要素数 2 の int 型の配列 [ [1, 2, 3], [4, 5, 6] ]
```

x は長さ(要素数)が 2 の配列ですが、その型は長さ 3 の整数配列ということになります。

:::note[限定的な使用となる配列]

Go では配列の大きさを配列の型の一部として扱います。つまり、`[3]int` と `[4]int` は別の型です。
配列の大きさを決定するのに変数などは利用できません。それはコンパイル時に配列の要素数は決定している必要があるためです。

- 配列の要素数はコンパイル時に決定している必要がある
- 配列の要素数は変更できない
- 配列の要素数は 0 以上でなければならない

配列を利用するのに適しているのは、暗号処理関連の処理などです。アルゴリズムの一部にチェックサムのサイズが定義されています。
次に紹介するスライスの後方支援的に利用します。

:::

## スライス

ほかの言語と同様な配列の理容方法としては、スライスがあります。
可変長配列とも呼ばれます。スライスの型には長さが含まれないため、配列のような宣言がありません。

```go
var x []int

var x = []int{1, 2, 3}

// [n] あるいは [...] と書くと配列になります。

var x = []int{1, 5: 4, 6, 10: 100, 15}
// 要素数 12 の int 型の配列 [1, 0, 0, 0, 0, 4, 6, 0, 0, 0, 100 15]
// 5: 4 は 5 番目の要素に 4 を代入、その間の要素は int のゼロ値 0 になる
// 10: 100 は 10 番目の要素に 100 を代入、その間の要素は int のゼロ値 0 になる
```

ゼロ値: `nil`

### スライスの特徴

- スライスの要素数は変更できる
- スライスの要素数は 0 以上でなければならない
- スライスの要素数は 2^31 - 1 を超えることはできない

スライスは型がない nil がゼロ値のため、スライス同志の比較はできません。スライスと比較できるのは nil です。

```go
var x []int

x == nil // true
x != nil // false
```

### スライスの要素に値を代入

配列同様、インデックスのサイズを超える要素の取得はできません。
要素に対する値の代入は以下のようにします

```go
var x = []int{1, 2, 3}
x[0] = 10
x[1] = 20
x[2] = 30
```

多次元のスライスを宣言することもできます。

```go
var x = [][]int{{1, 2, 3}, {4, 5, 6}}
// 要素数 2 の int 型の配列 [ [1, 2, 3], [4, 5, 6] ]
```

### append() 関数 (要素の追加)

スライスの要素を増やすには関数 append を利用します。

`append(スライス, 追加する要素...)`

```go
var x = []int{1, 2, 3}
x = append(x, 4, 5, 6)
// x は [1, 2, 3, 4, 5, 6] となる

// スライスに別のスライスを追加することもできます。
var y = []int{7, 8, 9}
x = append(x, y...)
// x は [1, 2, 3, 4, 5, 6, 7, 8, 9] となる
```

`...` 演算子を使うことでスライス内の個々の要素を展開して代入します。

戻り値は同じ型の新しいスライスです。戻り値を変数に代入せず利用しないとコンパイルエラーになります。

```go
package main

func main() {
	var x = []int{1, 2, 3}
	append(x, 4, 5, 6)
}
```

これを実行すると、

```
append(x, 4, 5, 6) (value of type []int) is not used
```

### スライスのキャパシティ

スライスは値が連続したもの。スライスの各要素はメモリ内の連続したメモリ領域に記憶されることで、素早い読み書きができるようになっています。
各スライスはキャパシティを持っています。あらかじめ一定個の連続する領域が確保されているのです。
この値は関数 len が返す値よりも大きい場合があります。スライスに append を行うと、1 個以上の値がスライスの最後に追加されます。
関数 len の値は値が一つ追加されるごとに 1 つずつ増加します。
len の値がキャパシティに達した場合、それ以上値を記憶できなくなりますが、
このような状態で値を追加しようとすると Go のランタイムがより大きなキャパシティを確保します。(メモリの再確保、2 倍になる)
最初のスライスのすべての値が新しいスライスにコピーされた上で、append に指定された値が最後に追加され、その結果できた新しいスライスが append からもどされることになります。

### スライスのコピー

スライスのコピーは関数 copy を利用します。

```go
var x = []int{1, 2, 3}
var y = []int{4, 5, 6}
copy(x, y)
// x は [4, 5, 6] となる
```
