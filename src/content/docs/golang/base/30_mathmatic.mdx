## ビット演算

ビット演算は、整数のビット単位で直接操作を行う演算です。Go 言語では、ビット演算子を使用して効率的にデータを操作したり、フラグの管理などに利用されます。以下では、Go における主なビット演算子とその使用方法について詳しく説明します。

:::tip[ビット演算って何？]

ビット演算（ビットえんざん）は、コンピュータがデータを扱う基本的な方法の一つです。コンピュータは情報を「ビット」という小さな単位で処理します。ビットは「0」と「1」の二つの値しか持ちません。

:::

### ビットとは

- **ビット**: コンピュータが情報を表現する最小単位。0 または 1 のどちらかの値を取ります。
- **バイト**: 8 ビットが集まったもの。コンピュータは通常、1 バイトを一つの文字や数字として扱います。

#### ビットの例

例えば、数字の「5」を 2 進数（バイナリ）で表すと「101」となります。これは以下のように解釈できます

```text
1 0 1
↑ ↑ ↑
4 2 1

左から順に、4の位、2の位、1の位です。
「1」はその位の数を足し、「0」は無視します。
```

### ビット演算の基本

ビット演算には主に 4 つの基本的な操作があります。それぞれを簡単な例で見てみましょう。

1. **AND（アンド）演算子 &**

   両方のビットが 「1」 の場合に結果が 「1」 になります。

   ```
     1 0 1
   & 1 1 0
   -------
     1 0 0  → 結果は「100」つまり4
   ```

1. **OR（オア）演算子 |**

   片方のビットが 「1」 の場合に結果が 「1」 になります。

   ```
     1 0 1
   | 1 1 0
   -------
     1 1 1  → 結果は「111」つまり7
   ```

1. **XOR（エクスクルーシブオア）演算子 ^**

   ビットが異なる場合に「1」になります。両方が同じ場合は「0」になります。

   ```text
     1 0 1
   ^ 1 1 0
   -------
     0 1 1  → 結果は「011」つまり3
   ```

1. **NOT（ノット）演算子 ~**

   ビットを反転します。

   ```
   ~ 1 0 1
   -------
     0 1 0  → 結果は「010」つまり2
   ```

   ビット演算は、最終的に 2 進数で表現されます。これはマシン語での処理するために使われます。

具体的な使い道は、

- フラグ管理

  例えば、ゲームでプレイヤーの状態(ジャンプ中、走っている、攻撃中など)をビットで管理します。各状態をビットで表すことで、一つの数値で複数の状態を管理できます。

- ビットマスク

  ビットマスクは、特定のビットを操作するために使用されます。例えば、データの特定のビットを読み取る場合、ビットマスクを使用して目的のビットを抽出できます。画像や音声データをビット単位で処理し、データ量を減らすことができます。

- ビットフラグの追加や削除

  ビットフラグの追加や削除は、ビット演算を使用して行うことができます。例えば、フラグの追加は OR 演算子を使用し、フラグの削除は AND NOT 演算子を使用します。

- 暗号化

  ビット演算は、データの暗号化や復号化にも使用されます。例えば、XOR 演算子を使用してデータを暗号化することができます。

#### ビット AND (`&`)

ビット AND 演算子は、両方のオペランドの対応するビットが 1 の場合にのみ結果のビットを 1 にします。それ以外は 0 になります。

```go
package main

import "fmt"

func main() {
    var a uint8 = 0b1010 // 10進数で10
    var b uint8 = 0b1100 // 10進数で12

    result := a & b
    fmt.Printf("a & b = %04b (%d)\n", result, result) // 出力: 1000 (8)
}
```

#### ビット OR (`|`)

ビット OR 演算子は、いずれか一方または両方のオペランドの対応するビットが 1 の場合に結果のビットを 1 にします。

```go
package main

import "fmt"

func main() {
    var a uint8 = 0b1010 // 10進数で10
    var b uint8 = 0b1100 // 10進数で12

    result := a | b
    fmt.Printf("a | b = %04b (%d)\n", result, result) // 出力: 1110 (14)
}
```

#### ビット XOR (`^`)

ビット XOR 演算子は、片方のオペランドのみが 1 の場合に結果のビットを 1 にします。両方が同じ値の場合は 0 になります。

```go
package main

import "fmt"

func main() {
    var a uint8 = 0b1010 // 10進数で10
    var b uint8 = 0b1100 // 10進数で12

    result := a ^ b
    fmt.Printf("a ^ b = %04b (%d)\n", result, result) // 出力: 0110 (6)
}
```

#### ビット AND NOT (`&^`)

ビット AND NOT 演算子は、左オペランドのビットから右オペランドのビットをクリアします。具体的には、右オペランドが 1 のビット位置において、左オペランドのビットを 0 にします。

```go
package main

import "fmt"

func main() {
    var a uint8 = 0b1010 // 10進数で10
    var b uint8 = 0b1100 // 10進数で12

    result := a &^ b
    fmt.Printf("a &^ b = %04b (%d)\n", result, result) // 出力: 0010 (2)
}
```

#### 左シフト (`<<`)

左シフト演算子は、数値のビットを指定した回数だけ左に移動させます。左にシフトすると、右側に 0 が挿入されます。

```go
package main

import "fmt"

func main() {
    var a uint8 = 0b0001 // 10進数で1

    result := a << 3
    fmt.Printf("a << 3 = %04b (%d)\n", result, result) // 出力: 1000 (8)
}
```

#### 右シフト (`>>`)

右シフト演算子は、数値のビットを指定した回数だけ右に移動させます。右にシフトすると、左側に 0 が挿入されます。

```go
package main

import "fmt"

func main() {
    var a uint8 = 0b1000 // 10進数で8

    result := a >> 3
    fmt.Printf("a >> 3 = %04b (%d)\n", result, result) // 出力: 0001 (1)
}
```

### ビット演算の使用例

ビット演算は、フラグの管理やビットマスクの適用など、効率的なデータ操作が求められる場面でよく使用されます。以下に具体的な例を示します。

#### フラグ管理

```go
package main

import "fmt"

// フラグの定義
const (
    Read    = 1 << iota // 0001
    Write               // 0010
    Execute             // 0100
)

func main() {
    var permissions uint8 = Read | Execute // 0101

    // フラグの確認
    hasRead := permissions&Read != 0
    hasWrite := permissions&Write != 0
    hasExecute := permissions&Execute != 0

    fmt.Printf("Read: %t, Write: %t, Execute: %t\n", hasRead, hasWrite, hasExecute)
    // 出力: Read: true, Write: false, Execute: true

    // フラグの追加
    permissions |= Write // 0111

    // フラグの削除
    permissions &^= Execute // 0011

    fmt.Printf("Updated Permissions: %04b\n", permissions) // 出力: 0011
}
```

### 注意点

- ビット演算は符号付き整数型 (`int`, `int8`, `int16`, `int32`, `int64`) と符号なし整数型 (`uint`, `uint8`, `uint16`, `uint32`, `uint64`) に対してのみ有効です。浮動小数点型やその他の型では使用できません。
- シフト演算において、シフトするビット数はオペランドのビット幅未満である必要があります。過剰なシフトは未定義の動作になる可能性があります。

```go
package main

import "fmt"

func main() {
    var a uint8 = 1
    var shift uint = 8

    // 過剰なシフトは未定義
    result := a << shift
    fmt.Printf("a << %d = %08b\n", shift, result) // 出力は未定義（多くの場合0）
}
```

### まとめ

ビット演算は低レベルなデータ操作において非常に強力なツールです。Go 言語では、シンプルかつ効率的にビット演算を行うための演算子が提供されており、フラグ管理やビットマスクの適用など、多くの場面で活用されています。ビット演算を適切に理解し活用することで、パフォーマンスの向上やコードの効率化を図ることができます。
