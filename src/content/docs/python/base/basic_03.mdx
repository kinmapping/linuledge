## ライブラリの分類

1. 型と関数
   関数には、print をはじめ、input、sum、abs などなど
   方には、コードの中であ扱える情報の性質を表す仕組み。
1. 組み込みライブラリとモジュール
   Python インタープリターに組み込まれている(Builtin)関数や型を提供するライブラリ。
   一方、Builtin 出ない型や関数はモジュールという枠で提供される。

### 関数

関数とは、何かしらの入力を与えることによって、あらかじめ決められた処理を行い、その結果を返す仕組みのこと。
関数の呼び出しは、`関数名(引数, ..., 引数名 = 値)` のように記述する。

- `値, ...` のように値を列挙するだけの引数を**位置引数**と言う
- `名前=値, ...` のように名前と値を組み合わせた引数を**キーワード引数**と言う

### 型

コードの中で扱える値の種類を決めるための仕組み。また、クラスとも言える。
クラスにたいして具体的な値を与えて、コードの中で利用できるようにすることをインスタンス化と言います。
型は設計図であり、インスタンスはその設計図を元に作成された実体です。

型に属する関数として、メソッドと呼びます。

str 型であれば

- 文字列から前後の空白を除去するための trim メソッド
- 指定の文字で分割する split メソッド
- 指定の文字で置き換える replace メソッド
- 指定の文字で検索する find メソッド

list 型であれば、

- リストの要素を追加する append メソッド
- リストの要素を削除する remove メソッド
- リストの要素を取得する get メソッド

メソッドの呼びだしは、`オブジェクト.メソッド名(引数, ..., 引数名 = 値)` のように記述する。

### 組み込み型/関数とモジュール

組み込み型とは、Python インタープリターに組み込まれている型のこと。
組み込み型の関数には、print や input などがあり、ソースの中で直接利用できます。(準備はいらない。)

一方、モジュールの関数は、モジュールをインポートすることで利用できます。

```python
import math
print(math.sqrt(16))
```

#### 特定のメンパーだけをインポートする

`import モジュール名`とすると、モジュールの中のすべての関数を利用できます。
しかし、必要な関数だけ呼び出すこともできます。

`from モジュール名 import 関数名, ...`とすると、モジュールの中の特定の関数だけを利用できます。

```python
from math import sqrt
print(sqrt(16))
```

## 文字列の操作

### 文字列の長さを取得する

```python
s = 'Hello, World!'
print(len(s)) # 13
s = 'こんにちは、世界！'
print(len(s)) # 9
```

len 関数では、日本語(マルチバイト)も正しく 1 文字としてカウントします。
もしも、半角を 1 文字、全角を 2 文字としてカウントしたい場合は、`len` の代わりに `east_asian_width` 関数(unicodedata モジュール)を利用します。

`east_asian_width` は、Unicode の文字の幅を取得する関数です。

### 文字列を検索する

#### 文字列の中で、特定の文字列が登場する文字位置を取得する

文字列の中で、特定の文字列が登場する文字位置を取得するには、`find`、`rfind`、`index`、`rindex` メソッドを利用します。

<Table
  caption=""
  colWidth={["10rem"]}
  columns={["メソッド", "説明"]}
  data={[
    ["`find`", "指定した文字列が登場する最初の位置を取得する"],
    ["`rfind`", "指定した文字列が登場する最後の位置を取得する"],
    ["`index`", "指定した文字列が登場する最初の位置を取得する"],
    ["`rindex`", "指定した文字列が登場する最後の位置を取得する"],
  ]}
/>

```python
# 文字列検索メソッドの使用例
text = "Hello World Hello Python"
#       012345678901234567890123

print("=== 元の文字列 ===")
print(text)

print("\n=== find() - 最初の位置を検索 ===")
print(f"'Hello' の位置: {text.find('Hello')}")  # 0
print(f"'World' の位置: {text.find('World')}")  # 6
print(f"'Python' の位置: {text.find('Python')}")  # 18
print(f"'Java' の位置: {text.find('Java')}")  # -1 (見つからない)

print("\n=== rfind() - 最後の位置を検索 ===")
print(f"'Hello' の最後の位置: {text.rfind('Hello')}")  # 12
print(f"'o' の最後の位置: {text.rfind('o')}")  # 22

print("\n=== index() - 最初の位置を検索（例外発生） ===")
try:
    print(f"'Hello' の位置: {text.index('Hello')}")  # 0
    print(f"'Java' の位置: {text.index('Java')}")  # ValueError: substring not found
except ValueError as e:
    print(f"ValueError: {e}")

print("\n=== rindex() - 最後の位置を検索（例外発生） ===")
try:
    print(f"'Hello' の最後の位置: {text.rindex('Hello')}")  # 12
    print(f"'Java' の最後の位置: {text.rindex('Java')}")  # ValueError: substring not found
except ValueError as e:
    print(f"ValueError: {e}")

# 実用的な例
email = "user@example.com"
at_position = email.find('@')
if at_position != -1:
    username = email[:at_position]
    domain = email[at_position + 1:]
    print(f"ユーザー名: {username}") # ユーザー名: user
    print(f"ドメイン: {domain}") # ドメイン: example.com

# ファイル拡張子の検索
filename = "document.txt"
dot_position = filename.rfind('.')
if dot_position != -1:
    extension = filename[dot_position + 1:]
    print(f"拡張子: {extension}") # 拡張子: txt

# 複数のキーワード検索
keywords = ["Python", "Java", "JavaScript"]
text = "I love Python programming"
for keyword in keywords:
    position = text.find(keyword)
    if position != -1:
        print(f"'{keyword}' が見つかりました (位置: {position})")
        # 'Python' が見つかりました (位置: 7)
    else:
        print(f"'{keyword}' は見つかりませんでした")
        # 'Java' は見つかりませんでした
        # 'JavaScript' は見つかりませんでした
```

### 文字列の前後から空白を除去する

文字列の前後から空白を除去するには、`strip`、`lstrip`、`rstrip` メソッドを利用します。

```python
文字列.strip()
文字列.lstrip()
文字列.rstrip()
```

<Table

strip メソッドはあくまで文字列の前後から空白を除去するメソッドです。そのため、文字列中の空白を取り除くには、`replace` メソッドを利用します。

```python
text = "  Hello World \t\n\r"
print(text.replace(' ', ''))
# HelloWorld
# \t\n\r はそのまま残る
```

#### 文字列の前後から特定の文字列を除去する(Python 3.9 以降)

Python 3.9 以降では、`removeprefix`、`removesuffix` メソッドを利用して、文字列の前後から特定の文字列を除去することができます。

```python
text = "Hello World"
print(text.removeprefix("Hello")) # World
print(text.removesuffix("World")) # Hello
```

<Table
  caption=""

```python
msg = 'WINGSプロジェクト'
```

### 文字列を特定の区切り文字で分割する

#### 一般的な分割 split / rsplit

split メソッドは、文字列を前方から、rsplit メソッドは後方から、それぞれ分割します。

```python
元の文字列.split(区切り文字)
元の文字列.rsplit(区切り文字)
元の文字列.split(区切り文字, 分割回数)
元の文字列.rsplit(区切り文字, 分割回数)
```

```python
# split と rsplit の使用例
text = "apple,banana,orange,grape"

print("=== 元の文字列 ===")
print(text)

print("\n=== split() - 前方から分割 ===")
print(text.split(','))  # ['apple', 'banana', 'orange', 'grape']

print("\n=== rsplit() - 後方から分割 ===")
print(text.rsplit(','))  # ['apple', 'banana', 'orange', 'grape']

print("\n=== 分割回数を指定した場合 ===")
print(text.split(',', 2))   # ['apple', 'banana', 'orange,grape']
print(text.rsplit(',', 2))  # ['apple,banana', 'orange', 'grape']

# 実用的な例
print("\n=== 実用的な例 ===")

# ファイルパスの分割
filepath = "/home/user/documents/file.txt"
print(f"ファイルパス: {filepath}")
print(f"split: {filepath.split('/')}")      # ['', 'home', 'user', 'documents', 'file.txt']
print(f"rsplit: {filepath.rsplit('/', 1)}") # ['/home/user/documents', 'file.txt']

# メールアドレスの分割
email = "user.name@example.com"
print(f"\nメールアドレス: {email}")
print(f"split: {email.split('@')}")      # ['user.name', 'example.com']
print(f"rsplit: {email.rsplit('@', 1)}") # ['user.name', 'example.com']

# 複数の区切り文字がある場合
data = "key1=value1;key2=value2;key3=value3"
print(f"\nデータ文字列: {data}")
print(f"split: {data.split(';')}")      # ['key1=value1', 'key2=value2', 'key3=value3']
print(f"rsplit: {data.rsplit(';', 1)}") # ['key1=value1;key2=value2', 'key3=value3']

# 空白文字での分割
sentence = "  Hello   World   Python  "
print(f"\n文章: '{sentence}'")
print(f"split: {sentence.split()}")      # ['Hello', 'World', 'Python']
print(f"rsplit: {sentence.rsplit()}")    # ['Hello', 'World', 'Python']

# 改行文字での分割
multiline = "line1\nline2\nline3"
print(f"\n複数行テキスト:\n{multiline}")
print(f"split: {multiline.split('\\n')}")      # ['line1', 'line2', 'line3']
print(f"rsplit: {multiline.rsplit('\\n', 1)}") # ['line1\nline2', 'line3']
```


- `align` : 寄せる方向

  - `>` : 右寄せ
  - `^` : 中央寄せ
  - `=` : 符号の後方を埋める

- `width` : 最小の表示幅
- `group_opt` : 桁区切り文字

  - `_` : 桁区切り文字(3 桁ごとにアンダースコアを挿入)
- `prec` : 有効桁数、type が f の場合は、小数点以下の桁数。g の場合は小数点前後の桁数
- `type` : 型
  - `%` : パーセント
  - `d` : 10 進数
  - `b` : 2 進数
  - `o` : 8 進数
  - `x`、`X` : 16 進数
  - `e`、`E` : 指数表記
  - `f`、`F` : 固定小数点表記
  - `g`、`G` : 指数表記か固定小数点表記
  - `s` : 文字列

### str 型、bytes 型を変換する

#### 文字列をエンコードする `encode`

Python の文字列は (str 型)は、文字列情報を Unicode データ(コードポイント)として保存します。
しかし、すべての環境で Unicode を前提にしているわけではありません。例えば、.py ファイルが Unicode(UTF-8) で保存されている場合でも、Windows のコマンドプロンプトでは、文字コードが Shift_JIS になっている場合があります。また、出力先のコンソールが EUC-JP を前提にしている場合もあります。そのような場合にも、正しく文字列を扱えるよう、Python では受け渡しのためのエンコーディング情報を管理しており、その情報に基づいて、文字列をエンコード変換しています。

このような変換処理は Python の内部的に実施するため、まずは、これをほとんど意識しなくても文字列を正しく扱えます。
しかし、文字列を別のアプリとやり取りするようになると、文字エンコーディングを意識して、明示的にエンコードしなければならない状況が出てます。これを行うのが、`encode` メソッドです。

```python
txt.encode(encording = 'utf-8', errors = 'strict')
```

- `txt` : エンコードする文字列
- `encording` : エンコーディング
  - `utf-8` : UTF-8
  - `shift_jis` : Shift_JIS
  - `euc_jp` : EUC-JP
  - `latin1` : ISO-8859-1
  - `ascii` : ASCII
  - `utf-16` : UTF-16
  - `utf-32` : UTF-32
- `errors` : エラー処理
  - `strict` : エラーが発生した場合は例外を発生させる
  - `ignore` : エラーが発生した場合は無視する
  - `replace` : エラーが発生した場合は置換する

例として、文字列を Shift_JIS でエンコードしてみます。

```python
txt = 'こんにちは'
print(txt.encode('shift_jis')) # b'\x82\xb1\x82\xf1\x82\xc9\x82\xbf\x82\xcd'
```

encode メソッドは、エンコードした結果を bytes 型で返します。
バイト列とは、単なる 0 ~ 255 の値の連なりなので、外部とのやりとりも自由です。バイト列を受け取った側も、その値を決められた形式で変換すれば、元の文字列を復元できます。

#### バイト列をデコードする `decode`

バイト列をデコードするには、`decode` メソッドを使用します。

```python
任意のバイト文字列.decode(encording = 'utf-8', errors = 'strict')
```
