`anyenv`を使用して`pyenv`をインストールし、その後で Python をインストールする手順を以下に示します。

1. **anyenv を利用する(anyenv のインストール)**

   `anyenv`をインストールします。`anyenv`は複数の**env**ツール（`rbenv`, `pyenv`, `nodenv`など）を一元管理するためのツールです。

   ```bash frame=none
   # anyenvのインストール
   git clone <https://github.com/anyenv/anyenv> ~/.anyenv
   echo 'export PATH="$HOME/.anyenv/bin:$PATH"' >> ~/.bashrc
   echo 'eval "$(anyenv init -)"' >> ~/.bashrc
   source ~/.bashrc
   ```

1. **anyenv-update プラグインのインストール**

   `anyenv` のプラグインである `anyenv-update` をインストールします。これにより、インストールされている env ツールを簡単にアップデートできます。

   ```bash frame=none
   mkdir -p $(anyenv root)/plugins
   git clone https://github.com/znz/anyenv-update.git $(anyenv root)/plugins/anyenv-update
   ```

1. **pyenv のインストール**

   anyenv を使用して pyenv をインストールします。

   ```bash frame=none
   anyenv install pyenv
   exec $SHELL -l
   ```

1. **pyenv による Python のインストール**

   pyenv を使用して Python をインストールします。

   ```bash frame=none
   # インストールできる python バージョンを確認
   pyenv install --list
   pyenv install 3.9.5

   # インストールした python のバージョンを確認
   pyenv versions

   # デフォルトの Python バージョンを設定

   pyenv global 3.11.4

   # shell セッションの python バージョンを確認
   python --version


   # プロジェクトごとにバージョン管理
   pyenv local 2.7.18
   ```
