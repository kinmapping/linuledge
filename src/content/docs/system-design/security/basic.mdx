## セキュリティの基礎

### セキュリティの基本原則

セキュリティの基本原則は、セキュリティを確保するための基本的な原則です。

## サイバーセキュリティ

サイバーセキュリティとは、関係のない第三者への情報漏洩を防止し、情報システムおよび通信ネットワークの安全性、信頼性を確保するため、必要な措置が取られ、適切に維持管理されていることです。

サイバーセキュリティ対策を行なっていないと以下のような被害が生じる可能性があります。

- ネットワーク経由でコンピュータに侵入されて重要な機密情報が盗まれる
- サーバーやシステムを攻撃・停止されてサービスの提供が不能になったりする
- ホームページの内容や重要なファイルの内容が改竄される
- 他のシステムへの攻撃の踏み台として利用される

### 標的攻撃型のサイバー攻撃

標的攻撃型のサイバー攻撃は、特定の組織や個人を狙った機密情報を狙った攻撃です。

- フィッシング攻撃
- ブラックメール攻撃
- マルウェア攻撃

さらにマルウェアが内部ネットワークに侵入したあと、数ヶ月後に活動を開始して情報を盗み出すという持続的に攻撃する APT 攻撃[^1]というものがあります。

[^1]: 先進的で(Advanced)、執拗な(Persistent)、脅威(Targeted)

標的型攻撃には、サイバーキルチェーン[^2]とよばれるモデルがあります。

[^2]: Cyber Kill Chain: https://www.lockheedmartin.com/en-us/news/features/cyberkillchain.html 、Lockheed Martin 社が提案したモデル

<Steps>

1. 偵察(Reconnaissance)

   ターゲット組織の内部情報収集をします。例えば、インターネット、メール情報、組織への侵入などが挙げられます。また、社員の SNS の情報などを調査して人間関係を調べるなども挙げられます。

1. 武器化(Weaponization)

   攻撃のためのエクスプロイトキットやマルウェアなどを作成します。

1. デリバリー(Delivery)

   マルウェアを添付した標的型メールを仕事関係のメールなどに見せかけて送りつけて感染させる

1. エクスプロイト(Exploitation)

   標的にマルウェアなどの攻撃ファイルを実行させる。または、悪意あるリンクにアクセスさせエクスプロイトを実行させる。

1. インストール(Installation)

   感染したマルウェアが活動を開始すると、さまざまなマルウェアをダウンロードし、感染を拡大。システムの脆弱性を突く

1. C&C(Command and Control)

   マルウェアと C&C サーバーが通信可能な状態となり、マルウェアの活動を報告する。また、C&C サーバーから感染したマルウェアに対してコマンドを送信する。最初に感染した組織のコンピュータはネットワークを移動して、より権限の高いコンピュータを感染させ、リモートから標的はの操作が可能となります。

1. 目的の実行(Action on Objectives)

   情報搾取や改竄、データ破壊、サービス停止など、攻撃の目的が実行される。機密情報を外部に送信し、自身の活動痕跡をログなどから消去する。

</Steps>

### サイバーセキュリティ対策

サイバーセキュリティ対策として、リスク管理体制を整えるため、SOC や CSIRT を設置することが大事です。

- **SOC(Security Operation Center)**

  ネットワークやパソコンなどの端末を監視し、企業に向けられたサイバー攻撃を検出して分析や対策を検討する部門や専門組織のこと。インシデントの検知に重点が置かれている。

- **CSIRT(Computer Security Incident Response Team)**

  ネットワークやパソコンなどで何らかのセキュリティ上の問題が万が一発生した場合に、それらのインシデントに対応するチームのこと。SOC と比較すると、インシデント発生後の対応に重点が置かれる。

これらの方法でセキュリティインシデントが発生しないように社員を啓蒙したり、セキュリティ対策に取り組んだり、また、万が一セキュリティインシデントが発生した場合にも、被害を最小限に抑えるための連絡体制をとるといった対策がおこなわれるようにしていきます。

#### セキュリティインシデントへの対応

セキュリティインシデントへの対応は、早期の検知と迅速な調査がが必要となります。インシデントが発生した際には、証拠保全を行います。(原因や被害を特定するための証拠となるデータ。)
ハードディスクや USB メモリ、スマートフォンなどに残る電子データを収集し、検査、分析、報告を行うことをデジタル・フォレンジックと呼び、原因や被害を検定し対応することで、セキュリティ対策の維持・向上に役立てます。

## セキュリティの構成要素

### ファイアウォール

組織内のネットワークとインターネットを接続する際に、不正なアクセスを防ぐための役割をもつ。

ファイアウォールの形態

- パケットフィルタリングタイプ

  パケットフィルタリングは、パケットの送受信を監視し、規定されたパケットのみを通過させる。

- アプリケーションゲートウェイタイプ

  アプリケーションを介在させ、不正な接続を遮断する

ファイアウォールの利用方法として、基本的な考え方は「危険にさらすのは特定のホストやルーターのみに限定する」という考え方です。どういうことかというと、ネットワーク内には 1000 台のホストがあるとすると、すべてに不正アクセスの設定や対策を施すことは手間がかかりますし、管理が煩雑になります。そのため、外部アクセスのためのホストを数台に限定し、安全なホストと危険にさらすホストを区別し、危険なホストにのみ集中してセキュリティをかけます。
例えば、ルーターを危険にさらすホストとして設定し、そのルータには特定の IP アドレスと、ポート番号が付けられているパケットのみを転送するように許可します。

- ネットワーク内の Web サーバーに対して TCP ポート 80 番でアクセス(HTTP アクセス)する通信を許可
- ネットワーク内の メールサーバーに対して TCP ポート 25 番でアクセス(SMTP アクセス)する通信を許可
- 社内ネットワーク内からの特定のカスタムポートへのアクセスを許可
- それ以外の通信パケットはすべて破棄

このように、危険にさらすホストを限定することで、セキュリティを高めることができます。
